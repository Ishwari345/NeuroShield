# 🛡️ NeuroShield - Autonomous Self-Healing Network Intrusion Detection System

## Overview

NeuroShield is an intelligent Intrusion Detection System (IDS) developed using Machine Learning and Reinforcement Learning techniques. The application analyzes network traffic from the NSL-KDD dataset, detects cyber attacks, and automatically recommends or performs appropriate response actions to improve network security.

I contributed to enhancing the project by improving the application, integrating additional functionality, refining the detection pipeline, and optimizing the overall system.

---

## Features

- 🔍 Network intrusion detection using the NSL-KDD dataset
- 🌲 Random Forest based anomaly detection
- 🧠 Artificial Neural Network (ANN) classification
- 🤖 Q-Learning based autonomous response system
- 🌐 Flask web interface
- 📊 Real-time attack prediction
- 🛡️ Automated response recommendation (Block / Alert / Allow)
- 📈 Interactive prediction dashboard

## Installation

Clone the repository

```bash
git clone https://github.com/Ishwari345/NeuroShield.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://localhost:5000
```
